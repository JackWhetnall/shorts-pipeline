If the phone can't connect

Windows Firewall has to let phones in, once. In a PowerShell window opened with Run as administrator:

netsh advfirewall firewall add rule name="Shorts Pipeline (phone)" dir=in action=allow protocol=TCP localport={{ port }} profile=private

That allows it on networks Windows calls private (your home Wi-Fi), not on public ones. If your home network is set to public, change it under Settings, Network & internet, Wi-Fi, your network, to Private. The phone must be on the same Wi-Fi as this PC. It's for your home network only: don't open this port on your router.
