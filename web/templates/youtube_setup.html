Read this before you rely on it

Google restricts uploads made through the API by projects that have not passed a compliance audit: their documentation states that videos uploaded this way from an unverified project created after 28 July 2020 are forced to private, whatever privacy setting is requested.

So until your project is audited, this uploads the video and everything around it, and you make it public yourself in YouTube Studio — one click instead of the whole manual upload. The audit is requested from the Cloud console once the project is doing real work.

1. Make an OAuth client

  1. Create (or pick) a project in the Google Cloud console.
  2. Enable the YouTube Data API v3 on it.
  3. Configure the OAuth consent screen. Add yourself as a test user. Leaving it in Testing works, but Google expires access every 7 days, so you would reconnect weekly. Publishing the consent screen stops that.
  4. Create credentials → OAuth client ID → application type Web application, and add this exact authorised redirect URI:

    {{ redirect_uri }}

    This is derived from the address you are reading this page on. Run the app on a different port and you will need to register that one too.
