This channel picks a topic at random from its list, so the same one can come up twice and there is no sense of easy before hard. A plan fixes both: an ordered syllabus, each topic used once, running from what anyone could follow to what only an enthusiast would search for.

How it works

First an outline is designed — one call, about {{ '%.2f'|format(cost.outline_usd) }} dollars — giving {{ default_units }} units in teaching order. You read those {{ default_units }} unit titles and decide whether the arc is right, which is a thing a person can actually do; {{ default_topics }} topics is not.

Then topics are written one unit at a time, as you approach needing them, each costing about {{ '%.2f'|format(cost.per_unit_usd) }} dollars. Filling the whole syllabus eventually comes to roughly {{ '%.2f'|format(cost.full_usd) }} dollars, spread over the eighteen months it takes to use.
