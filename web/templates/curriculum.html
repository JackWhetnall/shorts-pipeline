This channel picks from a flat list at random, so the same thing can come up twice and there is no sense of easy before hard. A plan fixes both: an ordered syllabus of topics, each holding the subtopics that become individual videos, running from what anyone could follow to what only an enthusiast would search for.

How it works

First an outline — one call, about {{ '%.2f'|format(cost.outline_usd) }} dollars — giving {{ default_topics }} topics in teaching order. You read those {{ default_topics }} titles and decide whether the arc is right, which is a thing a person can actually do; {{ default_subtopics }} subtopics is not.

Then subtopics are written one topic at a time, as you approach needing them, each costing about {{ '%.2f'|format(cost.per_topic_usd) }} dollars. Filling the whole syllabus eventually comes to roughly {{ '%.2f'|format(cost.full_usd) }} dollars, spread across the eighteen months it takes to use.
